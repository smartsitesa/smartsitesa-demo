# SmartSite SA Demo Spec

Purpose: serve as the mock-client demo and the reference workflow for future lead-specific demo builds.

## Offer
- R299/month
- professional business website
- mobile-friendly design
- basic SEO setup
- updates by WhatsApp
- ongoing maintenance
- monthly activity report

## Audience
- South African small businesses
- businesses with no website yet
- businesses relying only on WhatsApp/Facebook

## Core CTA
- Start on WhatsApp
- Message Charl directly

## Workflow Pattern
1. Gather public info for the lead
2. Create a lead-specific demo repo
3. Build a lead-specific one-page site
4. Publish to test GitHub Pages
5. Send outreach using that lead's own demo link
6. Track status/follow-up
